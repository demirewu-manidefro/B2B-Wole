Section 5: Security Architecture Guardrails

🔒 5.1 Concurrency Lock Engine

Wraps checkouts in explicit database transactions leveraging Pessimistic Locking (SELECT ... FOR UPDATE) to prevent negative stock race conditions.

🛡️ 5.2 Idempotent Webhooks

Cryptographic HMAC signature validation + DB unique constraint on tx_ref string. Duplicate webhooks drop out cleanly with 200 OK without multiplying balance records.

🛡️ 5.3 IDOR Perimeter Shield

Queries strictly reject isolated ID lookups, enforcing token-extracted identity scoping (WHERE id = ? AND vendor_id = current_user_id).

💬 5.4 Chat Security Scrubbers

Regex filters continuously scan Socket.io streams for phone numbers, bank accounts, or external links, obfuscating tokens and logging audit trails.
